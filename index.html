интеграция

Твой профиль слушает SPOKIDI

Rich Presence показывает трек, исполнителя, время и обложку — как у больших плееров.

  1. 01
    Создай приложение

    Developer Portal → New Application → SPOKIDI.

  2. 02
    Вставь Application ID

    В плеере: кнопка Discord → поле Application ID → Сохранить.

  3. 03
    Загрузи обложку

    Rich Presence → Art Assets → файл spokidi-discord-art.png, имя ассета spokidi.

  4. 04
    Играй

    Discord запущен — статус появится сам и будет обновляться.

ID — просто число, доступа к аккаунту он не даёт. На Android Discord-статус недоступен: там нет локального IPC.

вопросы

Коротко о важном

Это безопасно?

Да: плеер не ходит в сеть, не ставит службы и не просит аккаунт. Вся музыка и настройки — локально. Исходники рядом с сайтом, в папке проекта.

Почему Windows ругается на файл?

У exe нет платной подписи разработчика, поэтому SmartScreen показывает предупреждение. Нажми «Подробнее» → «Выполнить всё равно».

Почему в браузере плейлист может пропасть?

Браузер может очистить локальное хранилище страницы — например, при очистке данных или в приватном окне. В spokidi.exe и в Android-версии плейлист лежит внутри приложения и перезапуск переживает.

Можно свою картинку Годжо?

Да. Положи gojo.png рядом с spokidi.exe — портрет заменится при запуске.

А на телефоне будет статус в Discord?

Нет. Мобильный Discord не принимает локальные подключения, поэтому кнопка Discord в Android-версии скрыта.
